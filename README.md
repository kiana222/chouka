# AI 星愿

八位 AI 角色与独立专武的原创抽卡网页。使用原神式祈愿布局与流程，人物为静态立绘，过场包含云海、流星、品质变色和剪影揭晓。角色设定参考 ZipZipPipe，详见 [素材署名](LICENSES.md)。

支持角色池／专武池、八位主推切换、无限单抽和十连、跳过、逐张揭晓、总览、历史、图鉴与音效静音。手机请横屏。

## 规则

本项目采用原创娱乐规则：基础五星 5%、四星 15%、三星 80%。最多 20 抽必五星，最多 10 抽必四星以上，五星优先并重置四星计数。出五星时 50% 为主推，未中则下一五星必为当前主推。角色与武器池保底独立，切换同类池主推继承状态。

记录仅保存在当前浏览器。刷新会恢复未查看完的结果，不会重抽；重复获得累计数量。更换设备、域名或清除浏览器数据后不自动同步。请勿把它当作官方游戏概率模拟。

## 本机运行

安装有 Node.js 的电脑双击 `start.cmd`，或运行 `npm start`，打开 http://127.0.0.1:8847 。静态 ES 模块需要 HTTP 服务，请通过启动入口访问。

无需安装依赖，网页不调用大模型 API，不需要密钥。用 `npm test` 运行抽取规则测试。

## GitHub Pages

本仓库是静态网页，将 Pages 来源设为 `main` 分支的根目录 `/`。全部资源使用相对路径，支持项目子路径。仓库根目录的 `.nojekyll` 用于原样发布静态文件。

主页按需加载角色资源；全部图像均保存在仓库中，不依赖第三方图片站或 CDN。音效使用浏览器合成，首次点击祈愿后启用。
